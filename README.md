# Speech to Text Offline — clips

Short videos for the [Speech to Text Offline](https://play.google.com/store/apps/details?id=com.basikcode.transcriber)
Android app, published here only so the BasikCode social scheduler can fetch them by URL (GitHub Pages).
Distribution (TikTok + YouTube calendar) is owned by the private `basikcode-social` repo.

- `clips/<YYYY-MM>/*.mp4` — the month's clips (1080x1920, 30 fps)
- `manifest/<YYYY-MM>.csv` — `Date, Time, Text, Picture Url 1`; only the row order is used

Each clip is a real screen recording of the app transcribing the audio with **airplane mode on**.
Audio: [LibriVox](https://librivox.org) recordings, public domain.
